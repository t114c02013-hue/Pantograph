# 步驟計畫 v5：小動作序列與工具架規格

> 來源：專案負責人轉交（2026-10-14）。格式「指令（≤20 字）→目標→完成條件」；工具欄省略＝該步要用的工具。

## 共通規則
- 手上一次只能拿一件工具。手上有工具又去拿另一件 → 提示「先把○○放回工具架」，不算錯。
- 數字鍵 1–9 只高亮對應掛位，不直接切換工具。
- 小動作只在教學模式顯示（也只在教學模式要求依序完成）。
- 帶 {side} 的步驟 L、R 各跑一次，每側都從「到工具架拿起」開始。
- n=1→4 依 1、2、3、4 號螺栓展開成 4 個。
- 工具架 env.tool_rack.slot_1..9：1 上鎖掛牌組、2 驗電器、3 接地棒、4 安全帶、5 卡尺、6 套筒扳手、7 扭力扳手、8 清潔布、9 標記筆。每個掛位有名稱標籤，狀態：在架／使用中／空。
- 新增互動點：ip.cab.pan_indicator、ip.cab.raise_button、ip.depot.detector_tester、ip.depot.platform_anchor、ip.roof.anchor、ip.carbon_strip_{side}.install_check／install_target（CSR_11 到位判定，容許 EX 0.5 cm）。
- 升降：全程 15 秒，綠框前 20 cm 內減速。
- 預設完成的步驟：開場直接套用最終狀態（安全帶掛位使用中、鑰匙在背包），WC_01 清點才一致。

## 小動作序列
- SI_01：a 按住 ▼ 把弓頭降到綠框（距離 ≤1 cm）｜b 點弓頭確認已降下｜c 點控制盤弓位指示燈 ip.cab.pan_indicator
- SI_02（預設）：拿掛牌組 slot_1 → 主斷路器 OFF → 上鎖掛牌 → 升弓開關上鎖掛牌 → 放回 slot_1
- SI_03（預設）：電動缸電源 OFF → 按升弓鈕確認不動 ip.cab.raise_button
- SI_04：拿驗電器 slot_2 → 點自檢器 ip.depot.detector_tester（綠燈）→ 點弓頭接地掛點顯示無電 → 放回 slot_2
- SI_05：拿接地棒 slot_3（使用中）→ 夾接地端子 → 拉線確認 → 掛弓頭接地點（接地棒留在場上）
- SI_06（預設）：拿安全帶 slot_4（使用中）→ 扣平台掛點 → 鄰線檢查 5 項 → 扣車頂掛點 → 解平台掛點 → 簽名開工
- CSR_01：打開作業單看隔離狀態（SI 全部打勾）
- CSR_02：拿卡尺 slot_5 → 量爪完全合攏 → 按 ZERO 顯示 0.00
- CSR_03：量肘側左／中／右 → 三個讀數填入作業單（誤差 ≤0.05）
- CSR_04：同上（外側）→ 卡尺放回 slot_5
- CSR_05：依最小值選擇判定
- CSR_06_{side}：拿套筒扳手 slot_6 → 換 13 mm → 方向「鬆」→ {n} 號螺栓鬆半圈（180°±30°）
- CSR_07_{side}：{n} 號螺栓轉到脫出 → 放進零件盒（交替 8 個）→ 套筒扳手放回 slot_6
- CSR_08_{side}：點舊滑板「垂直取出」→ 放進零件盒
- CSR_09_{side}：拿清潔布 slot_8 → 擦托架 ≥95% → 放回
- CSR_10_{side}：看備品架三條標籤 → 旋轉檢查裂紋 → 拿卡尺 → 量選定新滑板中點 12.0±0.2 → 放回卡尺 → 拿起選定的新滑板
- CSR_11_{side}：新滑板移到托架上方 → 按 R 箭頭朝外 → 對準螺栓孔放下（install_target ≤0.5 cm 吸附）
- CSR_12_{side}：拿套筒扳手 → {n} 號螺栓放回孔位 → 方向「鎖」→ {n} 號螺栓鎖到貼合 → 放回
- CSR_13_{side}：拿扭力扳手 slot_7 → 設定 25 N·m → {n} 號鎖到喀聲（23–27）→ 放回
- CSR_14_{side}：拿標記筆 slot_9 → {n} 號畫標記 → 放回
- CSR_15：拿卡尺 → 量肘側新滑板中點 → 量外側 → 填作業單（差 ≤1.0）→ 放回
- WC_01：看工具架九個掛位（7 在架，接地棒與安全帶使用中）→ 看零件盒（只剩 2 條舊滑板）→ 按「清點完成」
- WC_02（預設）：安全帶扣平台 → 解車頂 → 放回 slot_4
- WC_03：取下弓頭端掛鉤 → 鬆開接地端子 → 接地棒放回 slot_3
- WC_04（預設）：拿掛牌組 → 解升弓開關 → 解主斷路器 → 放回 → 恢復電動缸電源 → 簽名完工
