# 新手入門指南：集電弓維修模擬器

寫給第一次打開這個專案的人。照順序做一遍，大約 30 分鐘。

---

## 0. 這個專案現在有什麼

| 項目 | 狀態 |
|---|---|
| Unity 版本 | **2022.3.62f3**（一定要用這個版本開，用別的版本會被升級或降級） |

| 預覽互動 | 按 ▶ Play：滑鼠環繞/縮放/平移、**空白鍵升弓/降弓動畫**、F 重置視角 |

## 1. 開啟專案

1. 打開 **Unity Hub** → 左邊點 **Projects**。
2. 找到 **collector shoes**，點一下就會開啟。
   - 如果清單裡沒有：點右上 **Add → Add project from disk**，選 `C:\黃泰翔\collector shoes`。
3. 確認版本欄寫的是 `2022.3.62f3`。如果 Hub 問你要不要換版本，**選取消**。

第一次開會比較久，因為 Unity 要建立 `Library` 快取，等它跑完就好。

## 2. 認識畫面（對照你的截圖）

```
┌──────────┬──────────────────────────┬────────────┐
│Hierarchy │  Scene / Game            │ Inspector  │
│ 場景裡   │  3D 畫面                 │ 選到的東西 │
│ 有什麼   │                          │ 的詳細設定 │
├──────────┴──────────────────────────┤            │
│ Project / Console                   │            │
│ 專案檔案 / 訊息與錯誤               │            │
└─────────────────────────────────────┴────────────┘
```

| 視窗 | 用途 | 新手要記住的 |
|---|---|---|
| **Hierarchy** | 目前場景裡所有物件的清單 | 點一下物件 = 選取它 |
| **Scene** | 編輯用的 3D 視窗，可以移動、旋轉物件 | 這裡改的東西要存檔（Ctrl+S） |
| **Game** | 玩家（受訓人員）實際會看到的畫面 | 由 Main Camera 決定看到什麼 |
| **Inspector** | 選取物件的屬性：位置、大小、元件 | Transform 的 Position / Rotation / Scale 最常用 |
| **Project** | 硬碟上 `Assets/` 資料夾的內容 | 等於檔案總管，**要搬檔案請在這裡搬，不要用 Windows 檔案總管**（會弄壞 .meta） |
| **Console** | 系統訊息 | 白色＝資訊、黃色＝警告、**紅色＝錯誤，一定要處理** |

> 你截圖裡那個黃色警告 `The layout ... could not be fully loaded` 是 Unity 的視窗排列設定，跟專案無關，可以忽略。

## 3. 打開起始場景、看模型

1. 在 **Project** 視窗進入 `Assets/_Project/Content/Scenes/`。
2. 雙擊 **PantographWorkshop**。
3. Hierarchy 會出現：`Main Camera`、`Directional Light`、`Ground`、`Pantograph`。
4. 點 `Pantograph` 旁邊的小三角形展開，可以看到模型裡的每個零件。

### 在 Scene 視窗移動視角

| 操作 | 做法 |
|---|---|
| 環繞查看 | 按住 **Alt + 滑鼠左鍵** 拖曳 |
| 平移 | 按住 **滑鼠中鍵** 拖曳 |
| 縮放 | **滾輪** |
| 飛行模式 | 按住 **滑鼠右鍵**，再按 **W A S D Q E** |
| 對焦到選取物件 | 在 Hierarchy 選好物件，滑鼠移到 Scene 上按 **F** |

### 編輯工具（鍵盤快捷鍵）

| 鍵 | 工具 |
|---|---|
| Q | 手掌（只移動視角） |
| W | 移動物件 |
| E | 旋轉物件 |
| R | 縮放物件 |

**練習**：選一個零件，按 W 拖動它，再按 **Ctrl+Z** 復原。

### 存檔

- **Ctrl+S** 存場景。視窗標題有 `*` 代表還沒存。
- 改壞了不想存：直接重新雙擊場景，選 **Don't Save**。
- 整個場景想重來：選單 **Tools → 集電弓 → 重建起始場景**。

## 4. 資料夾地圖：什麼東西放哪裡

```
collector shoes/
├─ ArtSource/            Unity 以外的原始檔（.blend .max .step），Unity 不會讀
├─ Docs/                 文件（你正在看的這份）
└─ Assets/
   ├─ Plugins/ ThirdParty/   外部購買或下載的套件，不要改裡面的東西
   └─ _Project/          ★ 我們自己的所有東西
      ├─ App/            程式進入點、啟動流程
      ├─ Core/           共用基礎：Events 事件、Interfaces 介面、Services 服務、Utilities 小工具
      ├─ Data/           Definitions 資料定義、Registries 登錄表
      ├─ Modules/        ★ 功能模組（模組化的核心）
      │  ├─ Parts/       集電弓零件，每個零件一個資料夾
      │  ├─ Tools/       維修工具：Caliper 游標卡尺、TorqueWrench 扭力扳手
      │  ├─ Procedures/  維修步驟（SOP）
      │  ├─ Faults/      故障情境
      │  ├─ Interaction/ 點選、抓取、拆裝的操作方式
      │  ├─ Training/    教學流程、評分
      │  ├─ UI/          介面
      │  └─ Persistence/ 存檔、學習紀錄
      ├─ Content/        場景、音效、環境、多語系
      ├─ ExternalModels/ 外部模型的「檢疫區」
      ├─ Editor/         只在編輯器用的工具（不會打包進程式）
      ├─ Settings/       專案設定檔
      └─ Tests/          自動測試
```

### 零件資料夾長這樣（每個零件都一樣）

以碳滑板 `Modules/Parts/CarbonStrip/` 為例：

| 子資料夾 | 放什麼 |
|---|---|
| Models | 這個零件的正式 3D 模型 |
| Materials / Textures | 材質、貼圖 |
| Prefabs | 組好的零件（模型＋腳本＋碰撞），場景裡用的是這個 |
| Scripts | 這個零件專屬的程式 |
| Data | 規格資料，例如磨耗極限、鎖固扭力 |

目前有 9 個零件：PanHead 弓頭、CarbonStrip 碳滑板、UpperArm 上臂、LowerArm 下臂、BaseFrame 底架、Insulator 絕緣子、LiftActuator 升弓裝置、Damper 阻尼器、AutoDropDevice 自動降弓裝置；`_Common` 放零件共用的東西。

**模組化的規則就一句話：改一個零件，只動它自己的資料夾。** 這樣以後別人接手改良某個部件，不會影響其他部分。

## 5. 加入新模型的流程

外部模型（網路下載、廠商提供、CAD 轉檔）**不能直接放進零件資料夾**，要先經過 ExternalModels 檢疫區：

1. 原始檔放 `ArtSource/`。
2. 匯出的 FBX 拖進 Project 視窗的 `ExternalModels/_Inbox/`。
3. 檢查：單位是不是公尺、軸向對不對、面數會不會太多、材質正不正常、**授權可不可以用**。
4. 沒問題就依來源搬到 `Vendor/<來源>/`、`CAD/` 或 `Scans/`，並改名成 `EXT_<來源>_<名稱>_v<版本>.fbx`。
5. 正式採用時，把整理好（減面、軸心擺正）的版本複製到 `Modules/Parts/<零件>/Models/`。
6. 在 `ExternalModels/README.md` 的模型清單記一筆。

> 注意：規範寫「正式場景不得引用 ExternalModels 的資產」。現在的 PantographWorkshop 是**預覽用**，直接用了 3d66 模型。等模型拆成各零件並放進 `Modules/Parts/` 之後，正式場景要改用零件的 Prefab。

## 6. 常見問題

| 狀況 | 原因／解法 |
|---|---|
| 開專案沒東西 | 預設開的是空白 Untitled 場景，去 `Content/Scenes/` 雙擊 PantographWorkshop |
| 模型變成粉紅色 | 材質的 Shader 跟目前渲染管線不符，或貼圖遺失。選模型 → Inspector → Materials 分頁檢查 |
| 模型超大或超小 | 匯出單位不是公尺。選 FBX → Inspector → Model 分頁調 **Scale Factor**，按 Apply |
| Console 出現紅字 | 點紅字看是哪個檔案哪一行；先不要按 Play，把錯誤截圖拿去問 |
| 檔案在 Windows 搬了之後壞掉 | 一定要在 Unity 的 Project 視窗搬，`.meta` 檔才會跟著走 |
| Hub 問要不要升級版本 | 取消，這個專案固定用 2022.3.62f3 |

## 7. 新手練習任務（依序）

1. 開專案 → 開 PantographWorkshop → 用 Alt+左鍵 繞模型一圈。
2. 展開 Pantograph，找出弓頭、碳滑板、上下臂分別是哪些子物件，記下名稱。
3. 切到 **Game** 視窗，選 Main Camera，調整 Position 讓畫面看到整台集電弓，Ctrl+S 存檔。
4. 在 Hierarchy 按右鍵 → **3D Object → Cube**，假裝它是工具箱，放在集電弓旁邊。
5. 在 Project 視窗 `Modules/Parts/CarbonStrip/Prefabs/` 試著把一個物件從 Hierarchy 拖進去，變成 Prefab（拖完可刪除，只是練習）。

做完這五個，就具備開始開發互動功能的基礎了。

---

## 8. 接下來專案要做什麼（給你一個大方向）

1. 把 3d66 模型拆成 9 個零件，放進各自的 `Modules/Parts/<零件>/`。
2. 在 `Core/` 定義共用介面，例如「可拆卸零件」「可量測零件」。
3. 在 `Interaction/` 做點選和拆裝。
4. 在 `Procedures/` 用資料（ScriptableObject）寫一份維修 SOP，例如「碳滑板磨耗檢查與更換」。
5. 在 `Training/` 把 SOP 變成一步一步的教學，加上評分。
