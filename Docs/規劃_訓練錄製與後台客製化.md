# 規劃：訓練錄製 ＋ 後台客製化訓練

> 狀態：草案 v0.1（2026-10-13），待確認第 8 節的決策後開始實作。

## 1. 目標

1. **錄製**：每次訓練（新人練習、資深人員示範）都自動錄下來，存到**指定資料夾**。
2. **教學**：資深人員可以回放錄製內容、在時間軸上加註解，整理成「教學包」給新人看。
3. **後台客製化**：資深人員/管理者不用改程式，就能調整訓練內容，例如指定維修程序、加入故障、設定時間限制、提示多寡、評分標準。

## 2. 角色

| 角色 | 能做什麼 |
|---|---|
| 新進人員（Trainee） | 選訓練、操作、看自己的錄製與成績、看教學包 |
| 資深人員（Trainer） | 錄製示範、回放任何人的錄製、加註解、發佈教學包、建立客製化訓練 |
| 管理者（Admin） | 設定錄製資料夾、管理帳號、匯出成績 |

## 3. 錄製：錄什麼、怎麼錄

### 3.1 兩種錄製方式

| 方式 | 內容 | 優點 | 缺點 |
|---|---|---|---|
| **A. 操作資料錄製（主要）** | 每個動作的事件：時間、步驟、零件、工具、量測值、攝影機位置 | 檔案小（幾百 KB）、可在 Unity 內回放並**任意換角度**、可自動評分與統計 | 只能在本系統裡回放 |
| B. 影片錄製（選配） | 畫面 MP4 | 任何播放器都能看、可放到簡報或內網 | 檔案大、不能換角度、不能分析 |

**建議**：以 A 為主，每次訓練一定會錄；B 做成「匯出影片」按鈕，從 A 的回放轉出 MP4。B 需要額外的錄影套件（Unity 內建的 Recorder 只能在編輯器用，打包後要用 FFmpeg 或第三方套件），列在第 3 階段。

### 3.2 運作原理（模組化的關鍵）

所有模組只負責**發出事件**，不知道錄製的存在；錄製模組只負責**監聽事件並寫檔**。以後新增零件或工具，只要發出標準事件，就會自動被錄到。

```
零件 / 工具 / 程序 / UI ──發出事件──▶ TrainingEventBus（Core/Events）
                                         │
                       ┌─────────────────┼──────────────────┐
                       ▼                 ▼                  ▼
                  Recorder          ScoreTracker        HintSystem
              （寫入錄製資料夾）     （即時評分）        （提示）
```

### 3.3 錄製的事件種類

| 事件 | 例子 |
|---|---|
| SessionStarted / SessionEnded | 誰、哪個訓練、開始/結束時間、結果 |
| StepEntered / StepCompleted / StepSkipped | 進入「步驟 3：量測碳滑板厚度」 |
| PartSelected / PartRemoved / PartInstalled | 拆下 CarbonStrip_L |
| ToolUsed | 用游標卡尺量測，讀值 21.4 mm |
| ToolSettingChanged | 扭力扳手設定 45 N·m |
| FaultDetected / FaultMissed | 找到/漏掉植入的故障 |
| MistakeMade | 順序錯誤、扭力不足、未斷電即操作 |
| HintShown | 系統給了提示 |
| CameraPose（每 0.2 秒取樣） | 視角位置，回放時重現受訓者在看哪裡 |
| Annotation | 資深人員在某個時間點加的文字/語音註解 |

## 4. 指定資料夾與檔案格式

### 4.1 位置

- 預設：`文件\CollectorShoesTraining\`
- 管理者可在後台改成**共用網路資料夾**（例如 `\\NAS\訓練中心\集電弓\`），讓所有電腦的錄製集中在一起。
- 設定存在 `TrainingSettings.json`，不寫死在程式裡。
- 錄製資料**不放在 Unity 的 Assets 裡**（那是開發用的，打包後不能寫）。

### 4.2 資料夾結構

```
CollectorShoesTraining/
├─ Recordings/                       ← 所有原始錄製
│  └─ 2026/10/
│     └─ 20261013-1412_T0123_CarbonStripReplace_a1b2/
│        ├─ session.json             ← 摘要：人、訓練、成績、版本
│        ├─ events.jsonl             ← 事件流，一行一個事件
│        ├─ annotations.json         ← 資深人員的註解（可後加）
│        ├─ thumbnail.png
│        └─ video.mp4                ← 選配
├─ Demonstrations/                   ← 資深人員的標準示範
├─ TeachingPackages/                 ← 發佈給新人的教學包（示範＋註解＋說明）
├─ Scenarios/                        ← 後台建立的客製化訓練設定
│  └─ CarbonStrip_Wear_Hard.json
├─ Reports/                          ← 匯出的成績表（CSV）
└─ TrainingSettings.json
```

命名規則：`<日期-時間>_<人員編號>_<訓練代碼>_<短亂碼>`，按檔名排序就是時間順序。

### 4.3 session.json 範例

```json
{
  "schemaVersion": 1,
  "sessionId": "a1b2c3d4",
  "mode": "Practice",
  "trainee": { "id": "T0123", "name": "王小明" },
  "trainer": { "id": "S0007", "name": "陳師傅" },
  "procedureId": "PROC_CarbonStrip_Replace",
  "scenarioId": "CarbonStrip_Wear_Hard",
  "appVersion": "0.1.0",
  "startedAt": "2026-10-13T14:12:03+08:00",
  "endedAt": "2026-10-13T14:31:47+08:00",
  "result": { "score": 82, "passed": true, "mistakes": 2, "hintsUsed": 1 }
}
```

`schemaVersion` 讓舊錄製在新版程式也讀得懂。

## 5. 回放與教學包

1. **回放器**：讀 `events.jsonl` 在場景中重演，可播放、暫停、快轉、拖時間軸、換視角（受訓者視角或自由視角）。
2. **時間軸標記**：錯誤（紅）、提示（黃）、步驟完成（綠），點一下就跳過去。
3. **註解**：資深人員暫停後輸入文字（之後可加語音），存進 `annotations.json`，不改動原始錄製。
4. **比對**：新人錄製與資深示範並排，或「幽靈模式」疊加顯示，看出差在哪一步。
5. **發佈教學包**：示範＋註解＋說明打包到 `TeachingPackages/`，新人在選單「學習區」看到。

## 6. 後台客製化訓練

### 6.1 可以客製化什麼

| 項目 | 例子 |
|---|---|
| 選維修程序 | 碳滑板更換、升弓壓力調整、絕緣子檢查 |
| 步驟開關 | 略過已熟練的步驟、只練某一段 |
| 植入故障 | 碳滑板磨耗到 17 mm、絕緣子裂痕、阻尼器漏油（從 Faults 模組的清單選） |
| 零件規格 | 磨耗極限、鎖固扭力（覆寫 Parts/*/Data 的預設值） |
| 難度 | 提示：全開 / 錯了才提示 / 關閉；時間限制 |
| 評分 | 各項權重、及格分數、哪些錯誤直接不及格（例如未斷電接地） |
| 指派 | 指定給某位或某組新人、到期日 |

### 6.2 運作方式

- 每個客製化訓練＝一個 **Scenario 檔**（JSON），放在 `Scenarios/`。
- 遊戲啟動時讀取這個資料夾，所以**資深人員新增或修改訓練，不需要重新打包程式**。
- 程式內建的預設程序、零件規格、故障清單用 ScriptableObject 定義（開發者維護）；Scenario 只是「引用＋覆寫」，不能憑空造出系統沒有的零件或故障，避免設定出錯。

```json
{
  "schemaVersion": 1,
  "scenarioId": "CarbonStrip_Wear_Hard",
  "title": "碳滑板磨耗判斷（進階）",
  "procedureId": "PROC_CarbonStrip_Replace",
  "faults": [ { "faultId": "FLT_CarbonStrip_Wear", "params": { "thicknessMm": 17.2 } } ],
  "hints": "OnMistake",
  "timeLimitMin": 20,
  "scoring": { "passScore": 80, "criticalMistakes": [ "MST_NoGrounding" ] },
  "assignedTo": [ "T0123", "T0124" ]
}
```

### 6.3 後台的形式（分兩步）

| 階段 | 形式 | 說明 |
|---|---|---|
| 第一步 | **程式內的「教官模式」** | 同一個 Unity 程式，用教官帳號登入後多出「後台」選單：建立 Scenario、看錄製、加註解、匯出成績。不需要伺服器，最快可用 |
| 第二步（視需求） | **網頁後台＋伺服器** | 多台電腦、多個訓練中心時再做：帳號集中管理、成績資料庫、從辦公室電腦遠端指派訓練 |

第一步就把資料格式（第 4 節）設計成檔案形式，第二步只是把「讀寫資料夾」換成「讀寫伺服器」，訓練本體不用改。

## 7. 對應到專案資料夾（模組劃分）

| 模組 | 位置 | 職責 |
|---|---|---|
| 事件與介面 | `Core/Events`、`Core/Interfaces` | `TrainingEvent`、`ITrainingEventBus`、`IRecordingStore`、`IScenarioProvider` |
| 錄製 | `Modules/Recording/`（新增） | Recorder、事件序列化、CameraPose 取樣 |
| 回放 | `Modules/Replay/`（新增） | ReplayPlayer、時間軸 UI、幽靈模式 |
| 儲存 | `Modules/Persistence/` | `FileRecordingStore`（資料夾）；將來加 `ServerRecordingStore` |
| 訓練流程 | `Modules/Training/` | Session 管理、評分、提示、讀取 Scenario |
| 程序／故障 | `Modules/Procedures/`、`Modules/Faults/` | SOP 定義、故障定義（ScriptableObject） |
| 後台 | `Modules/Admin/`（新增） | 教官模式 UI：Scenario 編輯器、錄製瀏覽、註解、匯出 |
| 帳號 | `Modules/Accounts/`（新增，小） | 人員編號、角色、簡易登入 |

每個模組一個 asmdef，只能往 `Core` 依賴，模組之間不互相引用，靠事件與介面溝通。換掉儲存方式（資料夾 → 伺服器）時，只換 `IRecordingStore` 的實作。

## 8. 需要你決定的事

1. **影片**：只要 Unity 內回放（A）就好，還是一定要 MP4（B）？
2. **資料夾**：每台電腦各自存，還是集中到共用網路資料夾/NAS？
3. **後台**：先做程式內教官模式（建議），還是一開始就要網頁後台？
4. **登入**：輸入人員編號就好，還是要密碼？要不要串公司既有帳號系統？
5. **設備**：桌機滑鼠操作，還是會用 VR 頭盔？（影響錄製的視角資料與互動設計）
6. **語音**：資深人員註解需不需要錄音？
7. **個資**：錄製含姓名與成績，保存多久？誰可以看？

## 9. 開發階段

| 階段 | 內容 | 完成標準 |
|---|---|---|
| **P0 基礎** | 事件匯流排、介面、asmdef 架構；碳滑板更換 1 個程序的最小可玩版本 | 能從頭操作到尾並在 Console 看到完整事件 |
| **P1 錄製** | Recorder ＋ 資料夾儲存 ＋ session.json | 訓練結束後指定資料夾出現完整錄製，換電腦也讀得到 |
| **P2 回放** | 回放器、時間軸、錯誤標記 | 能重演錄製，畫面與原操作一致 |
| **P3 教學** | 註解、示範模式、教學包、新人學習區 | 資深人員能做出一份教學包，新人能看到 |
| **P4 客製化** | Scenario 讀取 ＋ 教官模式編輯器 ＋ 指派 | 不改程式，新增一個帶故障的訓練並指派給新人 |
| **P5 報表** | 成績匯出 CSV、個人歷程 | 管理者匯出一個月的成績表 |
| P6 選配 | MP4 匯出、語音註解、網頁後台 | 依第 8 節決策 |

建議順序就是 P0 → P5；P0 一定要先做，因為錄製錄的是「操作事件」，沒有可操作的訓練就沒有東西可錄。

## 10. 風險

| 風險 | 對策 |
|---|---|
| 程式改版後舊錄製無法回放 | 每份錄製記 `schemaVersion` 與 `appVersion`，回放器做版本轉換 |
| 共用資料夾斷線導致錄製遺失 | 先寫本機暫存，結束後再同步到共用資料夾；同步失敗會重試並提示 |
| 後台設定出錯讓訓練跑不動 | Scenario 只能引用系統內建的程序/故障，載入時檢查並列出錯誤 |
| 個資外流 | 資料夾權限控管；匯出報表可選擇匿名 |
| 3d66 模型授權未確認 | 正式部署前確認授權，或改用自建/廠商模型 |
